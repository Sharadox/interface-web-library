# @sharadox/interface-web-library

Accessible, themable interface pieces for web applications: buttons, cards, dialogs, one-time code boxes, switches, text fields with prefixes, tips, copy buttons, skeletons and notifications.

Built from `template-web-library`: TypeScript in `source/`, one thing per folder, imports by package name, versions from 0.1.0, released by tagging `v<version>` on `index`.
